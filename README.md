# Career Quest

Career Quest — веб-приложение для сотрудников и HR по кейсу HackAlem AI / Halyk Bank. Оно связывает карьерную цель, требования следующего грейда, разрывы по навыкам и историю участия с конкретными шагами развития.

## Статус

Проект в разработке. Исходное техническое задание и синтетический датасет находятся в каталоге `ТЗ/`. После реализации здесь появятся точные команды установки, запуска, импорта и проверки основного сценария.

## Планируемая архитектура

- React + Vite + TypeScript — интерфейс сотрудника и HR.
- Node.js + TypeScript — API, проверка правил доступности, расчёт траектории и рекомендаций.
- PostgreSQL — профили, навыки, события и история участия.
- OpenAI API — персонализированное объяснение рекомендаций на основе проверенных сервером фактов.

Секреты будут храниться только в локальном `.env`; образец переменных — в `.env.example`.
